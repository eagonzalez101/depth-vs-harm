Pilot study · Chemical threats · AI safety

Does Claude's safety classifier mistake depth for danger?

On 75 expert-screened, benign chemical-threat questions, refusals climbed from 1% to 76% as the questions got more technical, landing hardest on biomedical questions.

Eduardo A González, PhD, chemical threat toxicology · November 2026
See the resultsFull studyCode and data

The question

25 chemical-threat topics. Each written at three levels of technical depth.

This pilot asks whether Claude's API safety classifier conflates technical depth with practical harm. Safety filters are meant to block information that helps cause harm. If they treat technical depth itself as a warning sign, they block the people with legitimate professional needs while adding little protection, since the same material sits in textbooks and clinical references.

Evidence that depth drives refusals

How it was done

Design

  • 25 benign chemical-threat topics, each written at 3 levels of technical depth: 75 prompts
  • Expert screen: no practical uplift, legitimate reason to ask
  • Depth check: the expert rated every prompt 1–5, blind to its level
  • Claude Opus 5.5 via the API, no system prompt, three runs each
  • Outcome: whether the safety classifier refused

Controls

  • Depth rated blind, before any model run
  • Prompts drafted by a different company's model
  • Refusal fallbacks disabled
  • Randomized order; 73 of 75 prompts gave the same outcome every run

Limitations

  • One expert chose topics, screened prompts and rated depth, with no second rater.
  • Deeper questions are also longer and more specific, so depth can't be fully separated from these variables.
  • Results apply to one model and classifier at one point in time.
